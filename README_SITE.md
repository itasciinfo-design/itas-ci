# Site scaffold — ITAS CI

Ce dossier contient un scaffold Next.js + TypeScript + Tailwind CSS pour le site vitrine de la société ITAS CI.

Commandes locales

- Installer les dépendances : `npm install`
- Lancer le serveur de dev : `npm run dev`
- Construire : `npm run build`

Déploiement

Je recommande Vercel (compte gratuit disponible). Créez un projet lié au dépôt et déployez.

Remarques

- Contenu et logo sont des placeholders. Fournissez le logo, les textes et la couleur si vous voulez que j'intègre vos éléments.
- Si vous souhaitez que j'ouvre une Pull Request depuis `site/scaffold` vers la branche par défaut, dites "Ouvre PR".
